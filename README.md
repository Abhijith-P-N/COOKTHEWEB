We engineer lightning-fast, secure, and SEO-optimized digital products for startups and enterprises across Palakkad, Kerala, Karnataka, and India.

---

## 🚀 Key Features & Highlights

- **Lightning-Fast Performance**: Engineered for near-instant load times (< 0.8s LCP), optimized assets, and 100/100 Lighthouse performance scores.
- **Modern Tech Stack**: Built with React 19, Vite 6, Tailwind CSS v4, and Framer Motion for buttery-smooth animations and transitions.
- **Regional & National SEO Dominance**: Hyper-optimized for search queries in **Palakkad, Kerala, Karnataka, and India** with dynamic route-aware meta tags, canonicals, and local business JSON-LD schema.
- **Direct Google Sheets Integration**: Contact form inquiries post securely and instantaneously into a Google Sheet via Google Apps Script Web App.
- **Interactive Founder Profiles**: Clean About section featuring co-founder profiles with interactive modal popups.
- **Project Shop**: Ready-to-deploy digital templates and live demos.
- **WhatsApp Integration**: Quick-access floating WhatsApp chat widget with passive scroll performance optimization.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router DOM v7
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Animations**: Framer Motion
- **Icons**: Lucide React & Custom SVGs
- **Build Tool**: Vite 6 (with esbuild minification & manual code-splitting)
- **Backend / Forms**: Google Apps Script (Google Sheets Web App API)

## ⚙️ Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation & Development
1. Clone the repository or open the project folder:
   ```bash
   cd D:\COOKTHEWEB
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open your browser at `http://localhost:5175`.

---

## 📦 Production Build

To build the optimized production bundle:
```bash
npm run build
```
The output will be generated in the `dist/` directory, ready to be deployed on Netlify, Vercel, or any static hosting provider.

To preview the production build locally:
```bash
npm run preview
```
